# Bank Service (Linux)

This repository contains a Bash script named `bank.sh` that provides a simple interactive bank service simulation for Linux.

## What it does

- Aadhaar bank service activation / deactivation
- Bank account membership queries
- Loan eligibility checks for home, personal, and vehicle loans
- Customer care help and guidance

## How to run

Open a terminal and run:

```bash
bash bank.sh
```

## Notes

- This project is for learning and demonstration only.
- The script runs locally and does not connect to any real banking service.
- The repository uses a simple shell script interface for Linux environments.
